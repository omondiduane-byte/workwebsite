The root is a single-package Vite + React project that bootstraps the frontend_app child. Build orchestration lives in package.json scripts (dev/build/lint/preview) and vite.config.ts, which registers the React plugin. TypeScript is configured as a project-references setup with tsconfig.json delegating to tsconfig.app.json (app code under src/* via @/* path alias) and tsconfig.node.json (Node tooling). Shared runtime configuration is centralized through .env/.env.example and a Supabase client initialized from environment variables. UI conventions are enforced by tailwind.config.cjs, postcss.config.js, components.json (shadcn), and eslint.config.js, which all children consume through the shared node_modules.
