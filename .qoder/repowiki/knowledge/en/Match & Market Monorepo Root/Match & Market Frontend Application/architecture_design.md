The app is a Vite + React entry point (`main.tsx` → `App.tsx`) that renders the entire UI from one large monolithic component. Data access is split across two Supabase client patterns: a direct `@supabase/supabase-js` client in `src/supabaseClient.ts` (hardcoded anon key) and an environment-driven client in `src/supabase/supabaseClient.ts` plus SSR-aware clients in `src/lib/client.ts` and `src/lib/server.ts` via `@supabase/ssr`. The `src/supabase/` folder also contains a thin typed wrapper `dbService.ts` that normalizes all Supabase calls into `{ data, error }` responses, and a domain-specific `inquiryService.ts`. UI primitives live under `src/components/ui/` (Button built on `@base-ui/react` with `class-variance-authority`, Card as plain divs), while `Ferrofluid.tsx` is a standalone WebGL shader visual using `ogl`. Styling is driven by Tailwind (`tailwind.config.js`) processed through PostCSS (`postcss.config.js`). All business state (vendors, menu items, cart, auth, approvals, delivery jobs, escrow ledger, chama deals, gas predictions) lives in React state inside `App.tsx` and is hydrated from Supabase tables on mount.
